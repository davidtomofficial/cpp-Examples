# Contributing to cpp-Examples

This repository preserves historical educational work. Focused documentation corrections, reproducible bug reports, and small improvements that retain the original learning context are welcome.

## Report an issue

Use this repository's [issues](https://github.com/davidtomofficial/cpp-Examples/issues). Identify the affected directory or file, explain the expected and observed behavior, and provide reproduction steps. For execution issues, include the compiler/version, build command, and relevant input files.

## Propose a change

1. Fork this repository and create a branch for a focused change.
2. Preserve assignment identifiers, original dates, author credits, and existing licensing notices.
3. For documentation changes, check relative paths, section anchors, and external destinations. For behavior changes, describe how you built or ran the affected example and what you verified.
4. Open a [pull request](https://github.com/davidtomofficial/cpp-Examples/pulls) against `main` with the reason for the change, a concise summary, and validation results or limitations.

Keep discussions respectful and specific. These historical examples have no promised release schedule or response time. See the [repository licensing notes](README.md#license) before proposing changes to licensing text or adding third-party material; this guide does not introduce a new license or contributor agreement.
